🚀I'm excited to share my recent DevOps project for Node.js applications!🎉 

I set up a CI/CD pipeline using Jenkins and expanded it with Kubernetes deployments managed through FluxCD.

🛠️ Key technologies and tools used:

Jenkins: Open-source CI/CD automation server with extensive plugin support.
Node.js: JavaScript runtime for scalable network applications.
SonarQube: Tool for continuous code quality inspection and vulnerability detection.
Docker: Platform for developing and running containerized applications.
Kubernetes: Container orchestration platform for automated deployment and scaling.
Flux CD: GitOps tool for automated Kubernetes application deployment.
Prometheus: Open-source monitoring system for collecting and querying time series metrics.
Grafana: Visualization platform for creating customizable dashboards from various data sources.

🔑 Here's a breakdown of my pipeline:

🔍 Git Checkout: Pulls the latest code from our main branch.
🔬 SonarQube Analysis: Ensures code quality and identifies potential issues.
🚦 Quality Gate: Verifies that our code meets predefined quality standards.
📦 Dependency Installation: Automatically installs all required npm packages.
🐳 Docker Build and Push: Creates a Docker image and pushes it to our repository.
🚀 Kubernetes Deployment: Automatically deploys our application to a Kubernetes cluster by syncing manifests from our GitHub repository using Flux CD.


This project provided an invaluable opportunity to further expand my DevOps expertise. By incorporating SonarQube for code quality assurance and leveraging Prometheus and Grafana for robust monitoring, I was able to build a more comprehensive and efficient CI/CD pipeline.I'm eager to apply these new skills to future projects, pushing the boundaries of DevOps even further! 🚀
